## ⚙️ GEAR PROGRESSION (60 Conjuntos)

### 5 Tiers por Classe

```
Tier 1 (Lvl 5-9)    → +5% bônus   (Novice)
Tier 2 (Lvl 10-14)  → +10% bônus  (Disciple)
Tier 3 (Lvl 15-19)  → +15% bônus  (Expert)
Tier 4 (Lvl 20-24)  → +20% bônus  (Master)
Tier 5 (Lvl 25-29)  → +25% bônus  (Legendary)
```

### Cada Tier Inclui
- Bônus de stats (primário + secundário)
- Bônus de elemento/dano
- Melhorias aos passivos
- Efeitos especiais (lifesteal, healing, etc)
- 2-4 itens únicos por conjunto
