# 🎨 Skill Icon Prompts for Leonardo.ai

## Configurações Recomendadas
- **Model:** Leonardo Kino XL ou Phoenix
- **Resolution:** 512x512 (quadrado para ícones redondos)
- **Preset:** Fantasy / Anime
- **Guidance Scale:** 7-8
- **Negative Prompt:** `text, letters, words, signature, watermark, blurry, low quality, realistic photo, photograph`

---

## 🎯 Estilo Base para Todos os Ícones
**Template de Prompt:**
```
circular skill icon, [ELEMENT COLOR] glowing energy, [SKILL VISUAL], dark background, fantasy RPG game UI, glossy orb style, magical aura border, sharp details, centered composition, no text
```

## 📁 Como Organizar os Ficheiros

Após gerar as imagens, guarde-as em:
```
public/assets/combat/skills/
├── fire/
│   ├── ember_slash.png
│   ├── flame_dance.png
│   └── ...
├── ice/
│   ├── frost_cut.png
│   └── ...
├── lightning/
├── wood/
├── void/
├── universal/
└── defense/
```

## 🔧 Integração no Código

Depois de ter as imagens, crie um ficheiro `src/data/skillAssets.ts`:

```typescript
export const SKILL_ICONS: Record<string, string> = {
  // Fire
  'BSI_001': '/assets/combat/skills/fire/ember_slash.png',
  'BSI_002': '/assets/combat/skills/fire/flame_dance.png',
  // ... etc
};

export const getSkillIcon = (skillId: string): string => {
  return SKILL_ICONS[skillId] || '';
};
```

E modifique a hotbar para usar as imagens em vez de emojis:

```tsx
// Em vez de:
<span className="text-xl">{skill.icon}</span>

// Use:
{getSkillIcon(skill.id) ? (
  <img src={getSkillIcon(skill.id)} className="w-8 h-8 object-cover rounded-full" />
) : (
  <span className="text-xl">{skill.icon}</span>
)}
```

## 💡 Dicas de Geração

1. **Batch Generation**: Gere 4 variações de cada e escolha a melhor
2. **Consistência**: Use o mesmo seed para variações de cor (ex: Fire → Ice)
3. **Upscale**: Use o upscaler do Leonardo para 1024x1024 após escolher
4. **Background Removal**: Se necessário, use o AI Canvas para remover fundo
5. **Post-Process**: Adicione brilho/glow no Photoshop/GIMP para efeito final
