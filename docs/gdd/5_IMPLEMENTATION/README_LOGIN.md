# 🎮 Como Configurar o Sistema de Login

## ⚡ Resumo Rápido (para quem tem pressa)

1. Vai a **https://supabase.com** e cria uma conta
2. Cria um novo projeto
3. Copia o **URL** e a **API Key** do projeto
4. Cola no ficheiro **`.env`** na raiz do projeto
5. Vai ao **SQL Editor** e corre o código SQL que está no ficheiro **SETUP.md** (Passo 5)
6. Reinicia o servidor: `npm run dev`
7. **PRONTO!** 🎉

## 🆘 Preciso de Ajuda!

### Não sei o que é Supabase
**R:** É como o Firebase mas grátis e mais fácil. É uma base de dados online onde vais guardar os dados dos jogadores.

### Não sei programar
**R:** Não precisas! Só tens de:
1. Criar a conta (como criar conta no Gmail)
2. Copiar 2 textos
3. Colar num ficheiro
4. Correr 1 comando

### Tenho medo de estragar algo
**R:** Impossível! A conta é gratuita e podes apagar e criar de novo sempre que quiseres.

### Quanto tempo demora?
**R:** 10-15 minutos na primeira vez. Depois já sabes fazer em 5 minutos.

---

## ✅ Depois de Configurar

O jogo vai mostrar uma página de **Login/Register** linda antes de jogar.

Os jogadores podem:
- ✅ Criar conta com email e password
- ✅ Fazer login
- ✅ Ter os dados guardados online (não perdem progresso)
- ✅ Jogar em qualquer computador
